# Basic IELTS Reading Unit 11

Imported from the user's `Unit 11 Vocabulary - Verified.pptx`, without modifying
the source deck. Unit 11 contains all 51 vocabulary slides in their original
order: 28 from Passage 1 and 23 from Passage 2.

Terms, parts of speech, definitions and examples retain the supplied text.
Slide headers, passage labels, footers and slide numbers are excluded from the
flashcards. `provenance.json` retains the original word fields, slide number,
passage and image relationship, crop, checksum and byte sizes.

All 51 pictures come from the matching source slide. The shared picture importer
preserves slide crops, fits pictures within 680 by 360 pixels and encodes WebP.
The original picture bytes remain in the uploaded PowerPoint; they are not
duplicated in the public site. Production URLs contain image content hashes.

Each cloze uses an actual occurrence of the word in its supplied example,
including plural and past-tense forms. Desensitised/desensitized,
spilled/spilt and non-profit/nonprofit/non profit are accepted where applicable.
The completed cloze always restores the source example exactly.

Reimport with:

```sh
python -B scripts/import_unit_11.py /absolute/path/to/source.pptx
```

The importer preserves all other books and unit records. Update the `data.js`
version hash in `dist/index.html` after importing. Counts, the source checksum
and picture sizes are recorded in `qa/unit-11-import.json`.
